## Why Convenient Window?

Windows multitasking shouldn't feel like hunting for tiny title bars and minimizing ten windows by hand. Convenient Window adds smooth, native-feeling controls directly to your screen edges and mouse—everything stays local on your PC.

      <p>Drag any window to the left, right, bottom, or top edge to tuck it into a slim strip. Hover the edge to slide it right back out.</p>
    </td>
    <td width="50%" valign="top">
      <h3>🧭 Hot Corners & Edges</h3>

    </td>
    <td width="50%" valign="top">
      <h3>🧩 Window Layouts</h3>
      <p>Save your current desktop arrangement—positions, sizes, snapped/hidden states, and pins—then restore it in one click or with a global hotkey.</p>

## Quick Start

1. **Download & run**: Grab the [**Windows Installer**](https://github.com/ximizhou/convenient_window_free/releases/download/v0.6.11/convenient-window-0.6.11-windows-x64-setup.exe) (recommended) or unzip the [**Portable ZIP**](https://github.com/ximizhou/convenient_window_free/releases/download/v0.6.11/convenient-window-0.6.11-windows-x64-portable.zip). Everything is bundled—no extra helper download needed.
2. **Turn on what you like**: Open Convenient Window from the system tray, flip the master switch on, and enable the features you want.
3. **Try edge hiding right away**: Drag any normal window to a screen edge until the blue line appears, then release (at the top edge, pause briefly until the line fills so regular Windows Snap still works). Move your mouse to the edge to bring it back.

Closing the settings window keeps Convenient Window active in the tray. Use the tray icon menu to reopen or quit.

<details>
<summary><strong>System requirements, privacy, and verification notes</strong></summary>

- **Platform**: Published packages target **Windows 11 x64**. macOS and Linux builds are not published for this release.
- **100% Local**: Window control, settings, and OCR run locally on your machine. OCR uses your installed Windows language packs and never uploads screenshots.
- **Unsigned builds & checksums**: Binaries are currently unsigned, so Windows SmartScreen may show an unknown-publisher prompt. Every [release](https://github.com/ximizhou/convenient_window_free/releases/tag/v0.6.11) ships `SHA256SUMS` and `artifact-manifest.json` so you can verify file integrity.
- **Updating the portable edition**: Extract the new archive over your existing folder—your settings live in Local AppData and stay intact.
- **Taskbar material (Experimental)**: Off by default; supports transparent, acrylic, and tinted styles on supported Windows 11 systems.

[All releases](https://github.com/ximizhou/convenient_window_free/releases) · [v0.6.10 rollback](https://github.com/ximizhou/convenient_window_free/releases/tag/v0.6.10)

<details>
<summary><strong>For developers: source layout, builds, and docs</strong></summary>

- `apps/desktop/` — Tauri 2 standalone host & shared Svelte settings UI
- `apps/dsh-plugin/` — DSH sidebar integration, native adapter & tests
- `helper/` — Single Rust engine for input hooks, window states, screenshots & OCR
- `scripts/` — Build, artifact audit, smoke test, and release scripts

Prerequisites: Node.js `24.14.0` (`.node-version`), pinned Rust toolchains (`rust-toolchain`), Visual Studio C++ Build Tools, and Windows SDK.

```powershell
npm ci
npm run desktop:install
npm run desktop:test
npm run desktop:check
npm run desktop:build
```
