# 0.6.4 development candidate

Local development candidate only; not published. Existing 0.6.3 stable assets remain unchanged. Interactive UAC, multi-monitor/DPI, taskbar recovery and host-adapter acceptance remain required.

- Add a default-on translucent hot-zone hover hint switch in Corner parameters. Turning it off hides only the desktop hint; hot-zone actions and the settings preview remain active.
- Add per-display, per-zone geometry controls: corner width/height with a ratio lock, edge thickness and 10–100% centered length, live preview and isolated reset. Migrate settings to schema v9 without changing legacy ranges; reject stale helper schemas.
- Fix topmost pins disappearing behind their stationary owner when stacking order changes, without placing them above every other topmost window.
- Keep pinned screenshots at their original pixel dimensions. The default-on offset moves them 16 px down/right; turning it off covers the captured area. Large or edge-adjacent images may extend off-screen instead of being automatically resized.
- Preserve unfinished numeric input until blur/Enter, keep drafts isolated between monitor/zone/trigger contexts, and wait for real display identities before saving monitor profiles.
- Preserve early helper shutdown notifications so starting and immediately stopping does not wait for a second exit request.
- Refresh the serializer dependency to the patched locked version without forcing a major test-tool migration.
- Add current-session Windows administrator-helper mode while keeping the host and configured commands at ordinary permissions. Re-query failed switches; show unknown if actual permission state cannot be confirmed.

- Keep the two grey runtime-center cards aligned with short descriptions; move administrator permission controls to the top-right Settings panel. Technical details are expandable, while failures and unknown-permission warnings stay visible.

Add a separate default-off Windows desktop preference to request administrator access at login. Only the login launch attempts one UAC prompt; cancellation falls back to ordinary mode, and an unconfirmed launch prevents replacement or repeated prompts. Settings and the tray share startup state. No scheduled task is created, foreground starts do not request login elevation, and disabling startup clears the login request. Other hosts retain their own startup policy. Administrator mode does not support protected processes. Each host adapter requires its own runtime acceptance. Hosts share the single-instance boundary and fixed port 56873. See [candidate tests](../testing.md#064-local-candidate-acceptance).
