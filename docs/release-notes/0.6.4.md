# 0.6.4 pre-release candidate

Public-download acceptance candidate, not a stable release. Existing 0.6.3 stable assets remain unchanged. Real UAC, taskbar recovery and installation/upgrade acceptance are still required.

- Add a default-on translucent hot-zone hint switch. Hiding the hover hint leaves all hot-zone actions active.
- Customize each display's corner width/height and ratio lock, or edge thickness and centered length, with live preview and per-zone reset.
- Fix topmost pins being hidden behind their stationary owner; keep the default-on pin option beside topmost actions without covering unrelated higher windows.
- Keep pinned screenshots at original pixel size, with an optional default-on 16 px offset. Large or edge-adjacent images may extend off-screen; manual move/resize remains available.
- Preserve unfinished number input until blur/Enter, isolate drafts between display/zone contexts, and fix clipped or jumping settings after master-switch changes.
- Show start/stop progress immediately and avoid redundant display-preview updates, without changing durable saves, ownership checks or single-instance protection.
- Simplify aligned runtime cards and gesture settings. Move permission controls to Settings and remove the redundant gesture overview while retaining the library, New, recording, actions and screenshot access.
- Add current-session administrator-helper mode while keeping the desktop interface and configured commands at ordinary permissions. Failed state queries display unknown instead of a cached permission badge; protected processes are not supported.
- Add a separate default-off request for administrator access at login. Login launches attempt one UAC prompt; cancellation falls back to ordinary mode. Startup settings and the tray stay synchronized; no scheduled task or silent elevation is used.
- Add a legacy taskbar-appearance path for Windows 10 1903+ / Windows 11 21H2 while retaining XAML on Windows 11 22H2+. Unsupported, conflicting and repeatedly failing operations stop retrying and show a reason. Legacy acrylic is a compatibility effect, with best-effort restoration to the system accent policy.
- Preserve early shutdown signals and improve recovery from permission failures, command-listener disconnects and quoted Windows commands.

Do not run competing hosts on the fixed helper port 56873. Windows 10 taskbar support does not constitute full Windows 10 desktop acceptance. See the [candidate tests](../testing.md#064-local-candidate-acceptance).
